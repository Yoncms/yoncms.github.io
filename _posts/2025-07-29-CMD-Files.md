# 通过CMS命令查询C盘的大文件
<pre>

不写入文件：<!--more-->
forfiles /P C:\ /S /M *.* /C "cmd /c if @fsize GEQ 104857600 echo @path @fsize"

写入文件：
forfiles /P C:\ /S /M *.* /C "cmd /c if @fsize GEQ 104857600 echo @path @fsize" > bigfiles.txt

边输出边写入（只能用powershell）：
powershell -Command "& { forfiles /P C:\ /S /M *.* /C 'cmd /c if @fsize GEQ 104857600 echo @path @fsize' | Tee-Object -FilePath bigfiles.txt }"
</pre>
