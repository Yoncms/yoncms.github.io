# MicrosoftEdgeWebView2Runtime损坏解决办法

MicrosoftEdgeWebView2Runtime<!--more--> 是 Microsoft 提供的 WebView2 运行时，用于让 Win32应用程序（如 Office、Teams、一些第三方工具）使用基于 Microsoft Edge (Chromium) 的网页渲染功能。如果该文件夹被手动删除了，但无法在“应用和功能”中卸载或重装，说明系统中的 WebView2 安装信息已损坏。

解决方法如下：  
通过 PowerShell 脚本自动下载安装 WebView2：  
Invoke-WebRequest -Uri "https://go.microsoft.com/fwlink/p/?LinkId=2124703" -OutFile "$env:TEMP\WebView2Installer.exe"
Start-Process "$env:TEMP\WebView2Installer.exe" -ArgumentList "/install" -Wait
